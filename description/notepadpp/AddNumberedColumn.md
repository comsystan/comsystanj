

### Add a column on the left with sequential numbering in a csv table with Notepad++

- Click with the cursor to the very top left position<br>
Press <b>Alt+C</b><br>
Select Text to Insert<br>
Type "**,**"<br>
Press **OK**<br>

- Click with the cursor to the very top left position<br>
Press **Alt+C**<br>
Select Number to Insert<br>
Select Dec<br>
Set Initial Number to "0"<br>
Set Increase by to "1"<br>
Let Repeat be empty<br>
Set Leading to "None"<br>
Press **OK**<br>

- Press **Ctrl+H** or go to Search/Replace<br>
Click Wrap around<br>
In the Find what field, enter a single space character<br>
Leave the Replace with field completely empty<br>
Ensure the Search Mode is set to Normal (not Regular expression)<br>
Press **Replace All**<br>

- Press **Ctrl+End**<br>
Delete last entry of the first column<br>
(Do not delete the CRLF of the last row)<br>
